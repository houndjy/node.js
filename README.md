# 김태년 기사 크롤러 (Windows EXE 지원)

김태년 관련 기사를 웹에서 수집하고, 요청한 조건으로 제목 유사도를 기반으로 묶어 보여주는 데스크톱 앱입니다.

## 요구사항 반영

1. **기사를 일자별 수집**: 기사 날짜를 추출해 저장합니다.
2. **동일 일자 유사 제목 묶기**: 같은 날짜 기사 중 유사 제목을 하나의 항목으로 그룹화합니다.
3. **1~2일 차이 기사도 90% 이상 유사 시 묶기**: 날짜 차이가 2일 이하이며 제목 유사도 0.90 이상이면 같은 항목으로 처리합니다.
4. **독립 실행 EXE 제공 가능**: `PyInstaller`로 `.exe` 생성.
5. **윈도우 크기 1600x1000**: 앱 시작 시 고정 기본 크기 적용.

## 실행 방법 (개발)

```bash
python -m pip install -r requirements.txt
python app.py
```

## Windows EXE 빌드

Windows CMD에서:

```bat
build_exe.bat
```

생성 파일:

- `dist\kimtaenyeon_news.exe`

## 사용법

1. 검색어(기본: `김태년`)와 페이지 수를 입력.
2. **크롤링 실행** 클릭.
3. 결과 표에서 더블클릭하면 대표 기사 링크를 브라우저로 엽니다.
